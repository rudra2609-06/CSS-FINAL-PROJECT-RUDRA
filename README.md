# My Simple Webpage

This project is a basic webpage created as a final CSS project. It demonstrates fundamental HTML structure and styling using CSS.

## Features

* **Clean and Simple Layout:** The webpage features a straightforward and easy-to-navigate design.
* **Header with Navigation:** A fixed header includes the website title and navigation links for "Home," "About," and "Contact."
* **About Section:** This section provides a brief introduction and includes links to my GitHub and LinkedIn profiles.
* **Contact Form:** A simple form allows visitors to enter their name and email.
* **Hero Image:** A visually appealing hero image adds a touch of design to the page.
* **Footer:** The footer displays a copyright notice and links to social media profiles.
* **Custom Fonts:** The project utilizes offline fonts for a unique typography.
* **Bootstrap Icons:** Icons from Bootstrap Icons are used for visual enhancements.
* **Responsive Design:** While not explicitly stated, the use of `max-width` and flexbox suggests some level of responsiveness across different screen sizes.

## Technologies Used

* **HTML:** Provides the structural foundation of the webpage.
* **CSS:** Styles the HTML elements to control the layout, colors, typography, and overall appearance.
* **Bootstrap Icons:** A library of free, high-quality vector icons.

## Files Included

* `index.html`: The main HTML file containing the webpage structure.
* `css/style.css`: The main CSS file containing the styling rules.
* `css/stylesheet.css`: Likely contains the declarations for the offline fonts used in the project.
* `fonts/`: A directory containing the offline font files.
* `images/hero_img.jpg`: The image used in the hero section.

## How to Use

To view this webpage, simply open the `index.html` file in any web browser. The associated CSS and other assets are linked within the HTML file.
